# mcp-code-explorer

MCP server in Python that lets AI clients list and read files within a sandboxed folder

Model Context Protocol is a way to give a model context it doesn't have. It is also the standard for how an AI client and server talk. The servers, such as GitHub or Notion offer tools to the client side to find and calll, which allows for any MCP client to use any MCP server eliminating the need for custom integration.
